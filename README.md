NuvioFit

An AI-powered fitness application that generates personalized workout programs.

---

What it does:

- Users fill out a questionnaire about their fitness goals, experience, and preferences.
- The system uses AI (OpenAI API + Python) to create customized exercise plans.
- Frontend built in React to display the workouts in a user-friendly format.
- Iterates based on user input and feedback to improve suggestions.

---

Technologies:

- Python
- OpenAI API
- React
- Web-based interface

---

Purpose:

Helps users achieve their fitness goals by generating tailored exercise routines quickly and efficiently.
